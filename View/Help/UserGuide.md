# Общие сведения
АС «ВРДО ПДГ» автоматически вводит режим по напряжению в допустимую область при подготовке мегаточки (МТ) для расчёта МДП в ПО Барс-МДП. Система изменяет загрузку управляемых СКРМ, состояние коммутируемых СКРМ и заданное напряжение генераторов по таблицам эффективности КП и дописывает изменения в файл smp_smzu.csv.
Порядок работы:
- выполните в ПО Барс-МДП макрос «Подготовка МТ»;
- загрузите в систему файлы smzu_mega_act.mptsmz и smp_smzu.csv (кнопка «Загрузить»);
- запустите расчёт (кнопка «Запустить») и просмотрите протокол;
- сохраните результаты (кнопка «Сохранить»);
- выполните в ПО Барс-МДП макросы «Актуализация МТ» и «Создание и актуализация МТ XML по УР».

# Загрузка данных
Нажмите «Загрузить». В окне «Загрузка данных» нажмите «Выбрать файл» в карточке «Мегаточка» и выберите файл smzu_mega_act.mptsmz, затем в карточке «Топология сети» — файл smp_smzu.csv.
- Серая карточка с пунктирной рамкой — файл не загружен, зелёная с флажком — файл загружен и прошёл проверку.
- Кнопка «Заменить» позволяет выбрать другой файл.
- Кнопка «Готово» доступна, когда выбраны оба файла.
После нажатия «Готово» система проверяет файлы, считывает файл smp_smzu.csv и МТ по каждому часу, получает границы графиков напряжений в КП и сохраняет данные в базу данных. Ход загрузки отражается в протоколе, итог — индикаторами «mptsmz» и «csv» на панели инструментов.
Границы графиков напряжений в КП временно приняты равными 500–525 кВ для всех КП и часов (запрос к ОИК «СК-11» будет реализован позднее). Если границы не удаётся получить, используются границы, сохранённые в базе данных, а в протокол записывается предупреждение «Не обновлены данные для проведения расчета».

# Запуск расчёта
Нажмите «Запустить». Для каждого часа и каждого КП система сравнивает напряжение в основном узле КП с границами графика. КП обрабатываются по убыванию отклонения напряжения от допустимой области: первым — КП с наибольшим отклонением. При выходе за границы СКРМ из таблицы эффективности КП перебираются группами:
- управляемые СКРМ: при снижении напряжения разгружаются до Qmin, при повышении загружаются до Qmax; отключённые СКРМ пропускаются;
- коммутируемые СКРМ, состояние которых не задано в файле smp_smzu.csv: при снижении напряжения включается реактор или отключается БСК, при повышении — отключается реактор или включается БСК;
- генераторы: заданное напряжение узла генератора (vzd) изменяется на 0,3 кВ, пока загрузка узла qg не станет равной qmin или qmax.
После каждого изменения рассчитывается установившийся режим. Если режим не сошёлся, изменение отменяется и система переходит к следующему СКРМ. Ввод режима в часе выполняется в два этапа:
- первый этап: изменение, после которого напряжение в другом КП, бывшее в допустимой области, вышло за границы графика, отменяется и откладывается — в протокол записывается предупреждение «Изменение отложено: напряжение в другом КП вышло за границы графика» с названием этого КП;
- второй этап выполняется, только если после первого этапа напряжение хотя бы в одном КП осталось вне допустимой области и есть отложенные изменения. Отложенное изменение принимается, если наибольшее отклонение напряжения среди всех КП уменьшается («Изменение принято с выходом за границы графика другого КП»), иначе отменяется («Изменение отменено: наибольшее отклонение напряжения в КП не уменьшилось»). В протоколе указываются наибольшие отклонения до и после изменения.
КП, напряжение в которых было вне допустимой области до изменения, вводятся при повторном проходе по КП часа или попадают в перечень невведённых. Ввод режима в КП заканчивается, когда напряжение вошло в допустимую область или задействованы все СКРМ таблицы эффективности.
Каждый расчёт начинается с исходного состояния загруженной МТ. Во время расчёта отображается строка хода расчёта с процентом выполнения.

# Остановка расчёта
Во время расчёта кнопка «Запустить» заменяется кнопкой «Остановить». После подтверждения расчёт останавливается по завершении текущего расчёта установившегося режима. Результаты незавершённого расчёта в архив не сохраняются.

# Протокол расчёта
Панель «Протокол расчёта» показывает записи в реальном времени. Метки записей:
- ВРДО — КП, в котором выполнялся ввод режима;
- ЧАС — час суток;
- СКРМ — действие с СКРМ;
- УР — результат расчёта установившегося режима;
- WARN — предупреждение;
- INFO — информационное сообщение;
- ERR — ошибка.
Записи образуют иерархию «КП → час → действия с СКРМ и результаты расчёта УР». Группа раскрывается и сворачивается щелчком, кнопка «Развернуть всё» / «Свернуть всё» раскрывает или сворачивает все группы. Переключатели меток на панели фильтра скрывают и показывают записи выбранных типов, кнопка «Все» возвращает все записи.

# Сохранение результатов
Нажмите «Сохранить» после завершения расчёта. По умолчанию предлагается путь загруженного файла D:\BarsMDP\Results\<ДДММГГ>\BarsCSV\smp_smzu.csv. Записи исходного файла сохраняются без изменений, во второй блок добавляются записи:
- 03 — пределы реактивной мощности управляемых СКРМ (Qмакс; Qмин);
- 20 — состояние реакторов и БСК (1 — включено, 0 — отключено);
- 01 — заданное напряжение на шинах генераторов.
Одинаковые изменения в соседних часах объединяются в одну запись.

# Просмотр результатов
Кнопка «Предпросмотр» открывает форму «Напряжение по часам». Переключатель «До расчёта» / «После расчёта» выбирает исходные данные МТ или результаты последнего расчёта, вкладки — энергосистему. Таблицы повторяют листы «U-500» файла «Анализ.xlsx»: КП энергосистемы выводятся блоками один под другим в том же порядке и с теми же столбцами.
- «U сш» — напряжение на шинах (vras). Синий фон — выше верхней границы графика, красный — ниже нижней. Цветом выделяются только напряжения от 400 до 600 кВ: узлы другого класса напряжения не выделяются. Исключение — КП 220 кВ «БЦБК» и «Петровск-Забайкальская»: их напряжение сравнивается с границами 220–252 кВ.
- «СКРМ» — заданное напряжение (vzd) и загрузка (qmin, фиолетовое число, Мвар) управляемого СКРМ, «Вкл» / «Откл» — состояние реактора.
- «U ген» — заданное напряжение генератора (vzd); «Откл» — узел генератора отключён.
- «—» — объект не найден в МТ.
Подсказка к столбцу показывает КП, раздел и номер узла или реактора.
Кнопка «К расчёту» возвращает в главное окно.

# Архив и сравнение расчётов
Кнопка «Архив» открывает список расчётов текущего сеанса. Отметьте два расчёта и нажмите «Сравнить». В каждой ячейке таблицы сравнения сверху выводится значение расчёта с меньшим номером, снизу — второго расчёта. Расчёты хранятся до закрытия программы.

# Таблица эффективности
Кнопка «Настройка» открывает окно «Таблица эффективности». Выберите КП в списке слева (поиск — по вхождению текста в наименование КП).
- Приоритет меняется кнопками «↑» и «↓», перетаскиванием строки за маркер слева или вводом номера.
- «Добавить СКРМ» добавляет строку: выберите тип СКРМ и введите номер узла (управляемые СКРМ), реактора (коммутируемые СКРМ) или узла подключения генератора из таблицы «Узлы» МТ (генераторы).
- Генераторы в таблице указываются номером узла подключения из таблицы «Узлы» МТ. Если к узлу подключено несколько генераторов, каждой строке с этим узлом соответствует свой генератор.
- Кнопка с корзиной удаляет СКРМ из таблицы.
- «По умолчанию» восстанавливает состав и приоритеты СКРМ согласно ПУР.
- «Сохранить» проверяет таблицу (повторяющиеся приоритеты и СКРМ, отсутствующие в загруженной МТ СКРМ) и записывает её в базу данных. СКРМ, которого нет в базе данных, но которое есть в МТ, добавляется в базу данных с наименованием из МТ; коммутируемое СКРМ с «БСК» в наименовании добавляется как БСК, остальные — как реакторы.
- Если исходные данные не загружены, СКРМ проверяются по базе данных, а генераторы указываются номером генератора; об этом сообщает подзаголовок окна.
Изменения действуют на следующие расчёты, в том числе СКРМ, добавленные из МТ после загрузки данных. Во время расчёта кнопка «Настройка» недоступна.

# Сообщения об ошибках
- «Не найден файл с исходными данными» — файл отсутствует по указанному пути.
- «Формат файла не распознан» — выбран файл с другим расширением.
- «Нет доступа к файлу» — файл занят другой программой или нет прав на чтение или запись.
- «Неправильно заполнен файл исходных данных» — строка файла smp_smzu.csv не соответствует формату; в протоколе указан номер строки.
- «Не обновлены данные для проведения расчета» — границы графиков напряжений не получены, используются сохранённые в БД.
- «Ошибка обращения к ПО «Барс»» — не удалось открыть МТ или выполнить расчёт средствами ASTRALib.
